- [ ] Настроить форматирование, lint и проверку TypeScript.
- [ ] Добавить базовую структуру каталогов.
- [ ] Зафиксировать архитектурные типы и правила.
- [x] Добавить README и проектную документацию.

Критерий завершения: проект запускается локально, проходит проверки и имеет понятную структуру.

## Этап 1. Ядро данных

- [ ] Реализовать модели Entity, Relation, Board и BoardNode.
- [ ] Настроить IndexedDB и миграцию схемы.
- [ ] Реализовать репозитории и базовые операции CRUD.
- [ ] Добавить проверку ссылочной целостности.

Критерий завершения: данные создаются, читаются, редактируются и сохраняются после перезапуска.

- [ ] Отображать сущности на canvas.
- [ ] Создавать узлы из общей базы.

- [ ] Создавать типизированные связи.
- [ ] Добавлять существующую сущность на другую доску.

- [ ] Сделать список сущностей.

Критерий завершения: базой можно пользоваться без обязательного перехода на граф.

## Этап 4. Надёжность данных

- [ ] Реализовать JSON-экспорт всей базы.

## Этап 5. Подготовка к расширению

- [ ] Продумать модуль задач и представление списка задач.
- [ ] Продумать модуль проектов и связанный контекст.
- [ ] Добавить источники и метаданные происхождения информации.

## Правило приоритизации

Сначала целостность данных и надёжные базовые сценарии, затем визуальные эффекты и дополнительные модули. Каждая итерация должна оставлять приложение в запускаемом состоянии.
