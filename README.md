# Nodebase

**Personal Knowledge & Project OS** — локальная, расширяемая система для управления знаниями, проектами, людьми и связями между ними.

Nodebase — самостоятельный инструмент. Он должен полноценно работать без ИИ и не зависеть от ChatGPT, конкретного облака или внешнего сервиса.

## Принципы

- **Связанная база данных:** сущность создаётся один раз и может использоваться на разных досках.
- **Граф как интерфейс:** визуальные доски помогают исследовать связи, но не являются единственным способом работы с данными.
- **Local-first:** пользовательские данные хранятся локально; приложение полезно без сети.
- **Переносимость:** экспорт и импорт в документированном формате.
- **Постепенное развитие:** сначала надёжное ядро, затем дополнительные модули и интеграции.
- **Контроль над данными:** происхождение, актуальность и достоверность сведений должны быть различимы.

## Текущий статус

Начальный технический каркас MVP:
- React + TypeScript + Vite;
- доменные модели Entity, Relation, Board и BoardNode;
- IndexedDB через Dexie;
- создание и архивирование сущностей;
- базовый интерфейс со списком объектов;
- GitHub Actions для сборки и публикации на GitHub Pages.

Графическое редактирование, связи, экспорт/импорт и синхронизация ещё не реализованы.

## Локальный запуск

Требуется Node.js 22.

    npm install
    npm run dev

Для production-сборки:

    npm run build
    npm run preview

Данные приложения хранятся в IndexedDB текущего браузера и профиля. Очистка данных сайта в браузере может удалить локальную базу. До реализации экспорта не используйте тестовую базу для хранения единственных копий важных сведений.

## Публикация

Workflow `.github/workflows/deploy.yml` автоматически собирает приложение и публикует его на GitHub Pages после каждого push в `main`.

Первичная настройка:
1. Откройте Settings → Pages в репозитории.
2. В разделе Build and deployment выберите Source: **GitHub Actions**.
3. Дождитесь успешного выполнения workflow во вкладке Actions.

Ожидаемый адрес проекта: https://yurapankov.github.io/nodeprojectbase/

**Важно:** репозиторий сейчас приватный. GitHub Pages для приватных репозиториев доступен на тарифах GitHub Pro, Team и Enterprise. На GitHub Free Pages доступен для публичных репозиториев. Сам опубликованный сайт будет общедоступен в интернете (если не используется специальный режим приватной публикации на Enterprise). Не переводите репозиторий в публичный режим, если не готовы открыть исходный код. Пользовательские данные приложения не публикуются: они хранятся отдельно в IndexedDB браузера.
